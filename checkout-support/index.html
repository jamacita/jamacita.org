Checkout & Module Delivery Support

This route is prepared for payment, document-delivery and access issues relating to future Jamacita Solutions modular-analysis purchases.

Payment confirmed, no module yet

During the controlled pilot, a final release check may occur after payment. Support begins once the stated delivery window has passed.

Download link expired

A purchaser will be able to request a new link after entitlement is verified against the Order ID and business purchase record.

File unreadable

Technical file or link problems can be corrected without changing the underlying analytical entitlement.

Obvious factual transcription error

A purchaser may identify the Order ID, page and specific item for review. Analytical disagreement alone is not a technical file defect.

Duplicate charge

Duplicate or erroneous payment issues will be reconciled through the relevant transaction reference. Full card details should never be sent by email.

Invoice or receipt

Billing questions can be matched to the Order ID and purchaser organisation after the invoicing structure has been approved.

Order reference

The future support flow will use the Jamacita Order ID as its primary transaction reference.

The verified business support contact will be added only at activation.
